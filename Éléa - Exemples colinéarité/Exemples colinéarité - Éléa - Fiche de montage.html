Exemples colinéarité – Éléa – Fiche de montage

Ce dossier contient la version Éléa de la page Exemples colinéarité.html : le même cours, les mêmes exercices (vecteurs et points identiques à la feuille Exemples colinéarité.pdf), avec pour chaque question un point méthode affiché sous la consigne, deux indices successifs en cas d'erreur, puis une correction par étapes où les droites sont tracées sur la figure.

1. Importer la banque de questions (5 min)

Dans le parcours Éléa : Plus → Banque de questions → Importer. Format : Moodle XML. Fichier : Exemples colinéarité - Éléa - Banque de questions.xml. Laisser « Obtenir la catégorie du fichier » coché.

Les questions arrivent dans la catégorie Séquence 2 – Vecteurs › Exemples colinéarité (9 questions). Les figures sont incluses dans le fichier ; les formules s'affichent grâce au filtre MathJax d'Éléa.

2. Ajouter le cours (2 min)

Ajouter une activité Page nommée « Cours – Vecteurs colinéaires ». Ouvrir Exemples colinéarité - Éléa - Cours.html dans un navigateur, tout sélectionner, copier et coller dans le contenu de la Page (ou coller le code source avec le bouton « </> » de l'éditeur).

3. Créer le test (5 min)

Ajouter une activité Test nommée « Exemples colinéarité », puis dans les paramètres :

  • Comportement des questions : « Interactif avec essais multiples » (c'est ce qui affiche les indices après une erreur) ;
  • Mise en page : une question par page, navigation libre ;
  • Options de relecture : cocher « Feedback spécifique », « Feedback général » et « Réponse juste », pendant et après la tentative (le feedback général contient la correction par étapes) ;
  • Questions : ne pas mélanger, pour garder l'ordre de la feuille ;
  • Nombre de tentatives : illimité ; méthode de notation : note la plus haute.

Dans Questions → Ajouter → depuis la banque de questions, choisir la catégorie Exemples colinéarité et ajouter les 9 questions dans l'ordre : Ex1-Q1, Ex1-Q2a, Ex1-Q2b, Ex1-Q3, Ex1-Q4, puis Ex2-Q1 à Ex2-Q4.

Restriction d'accès conseillée sur le test : « Achèvement d'activité : la Page Cours doit être consultée ».

4. Ce que voit l'élève

  • la consigne et la figure, puis le point méthode (encadré jaune) ;
  • après une mauvaise réponse : un indice, puis un second indice plus précis ;
  • une fois la question terminée : la correction (encadré vert) avec les droites tracées, et la remarque « Vérifier avec les carreaux ».

Saisie des coefficients (Ex1-Q4, Ex2-Q2, Ex2-Q3) : les élèves écrivent par exemple -2 ou 3/2. Une écriture décimale (1,5) est refusée avec un message rappelant la convention.

Variante H5P (sans import de banque de questions)

Le fichier Exemples colinéarité.h5p contient tout dans une seule activité (présentation H5P de 36 diapositives) : le cours, puis pour chaque question une diapositive « question » (figure + point méthode + question interactive), suivie des diapositives de correction étape par étape, avec les droites tracées. Passer à la diapositive suivante = « étape suivante ». Une diapositive bilan donne le score à la fin.

  1. Activer le mode édition, puis Ajouter une activité ou ressource → H5P.
  2. Donner un nom (« Exemples colinéarité »), puis glisser Exemples colinéarité.h5p dans la zone « Fichier du paquet ».
  3. Enregistrer et afficher.

Saisie des coefficients entiers : -2, 3… Les coefficients fractionnaires sont proposés en choix (H5P ne permet pas de taper une fraction).

Le paquet est régénéré par build_h5p_colinearite.py (même dossier).

Modifier le contenu

Tout est généré par build_elea_colinearite.py (même dossier) : modifier le texte dans ce fichier puis lancer python3 build_elea_colinearite.py pour régénérer les trois fichiers, puis réimporter le XML.
