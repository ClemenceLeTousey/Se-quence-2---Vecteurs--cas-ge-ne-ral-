Séquence 2 – Éléa – Fiche de montage

Séquence 2 – Vecteurs : parcours Éléa différencié

Fiche de montage. Temps estimé : 1 h à 1 h 30 pour tout assembler une première fois. Les fichiers à utiliser sont dans le même dossier que cette fiche.

1. Principe

Le parcours est découpé en 4 blocs qui suivent le cours. Dans chaque bloc, un test d'entrée (6 questions tirées au hasard dans la banque du bloc) aiguille automatiquement l'élève, grâce aux restrictions d'accès de Moodle :

Note au test d'entréeCe que l'élève voit ensuite
< 50 %Je révise : page de rappel + vidéos + 3 exercices corrigés + exercices ★ des feuilles
50 % à 79 %Je m'entraîne : exercices ★★ des feuilles et du manuel (corrigé PDF déposé)
≥ 80 %Je vais plus loin : exercices ★★★ + activité Capytale du bloc
—Je valide : test de validation (6 autres questions de la même banque), visible une fois l'étape précédente achevée. Il débloque le bloc suivant.

Pendant les tests, chaque question fournit deux indices successifs (le second renvoie au paragraphe exact du cours et à la vidéo), puis un corrigé avec renvoi aux exercices. C'est le mode « interactif avec essais multiples » de Moodle.

2. Importer la banque de questions (5 min)

  1. Dans le parcours Éléa : menu Plus → Banque de questions → Importer.
  2. Format : Moodle XML. Fichier : Séquence 2 - Éléa - Banque de questions.xml. Laisser « Obtenir la catégorie du fichier » coché.
  3. Après l'import, la banque contient la catégorie Séquence 2 – Vecteurs et ses sous-catégories :
Sous-catégorieQuestions
0 – Positionnement (prérequis)5
Bloc 1 – Définition d'un vecteur15
Bloc 2 – Somme et relation de Chasles15
Bloc 3 – Produit par un réel, colinéarité15
Bloc 4 – Décomposition, alignement, milieu15
Bilan – synthèse4

Les figures sont incluses dans le fichier XML (il n'y a rien d'autre à téléverser). Les formules s'affichent grâce au filtre MathJax, activé par défaut sur Éléa. Vérifier sur une question : Aperçu.

3. Créer les sections et les activités

Réglages communs à tous les tests (Test → Paramètres) :

  • Comportement des questions : « Interactif avec essais multiples » (c'est ce qui affiche les indices).
  • Nombre de tentatives : 2 pour les tests d'entrée, illimité pour les tests de validation. Méthode de notation : note la plus haute.
  • Options de relecture : cocher « Feedback spécifique », « Feedback général », « Réponse juste » pendant et après la tentative.
  • Mise en page : une question par page, questions mélangées.
  • Achèvement d'activité : « L'élève doit recevoir une note ».

Pour remplir un test : Questions → Ajouter → une question aléatoire, choisir la sous-catégorie du bloc, nombre de questions = 6. Les deux tests (entrée et validation) d'un même bloc tirent dans la même sous-catégorie : Moodle ne retire pas les questions déjà vues, mais avec 15 questions par bloc le recouvrement est faible ; on peut aussi ajouter à la main 6 questions fixes pour le test d'entrée et laisser l'aléatoire pour la validation.

Section 0 – Avant de commencer

  • Test « Positionnement » : 5 questions de la sous-catégorie 0 – Positionnement, 1 tentative, non comptabilisé (note maximale 0 ou catégorie de notes « hors total »).
  • Fichier : Séquence 2 - Cours - Vecteurs.pdf ; Fichier : version Grands Caractères, avec restriction d'accès « Groupe » = le groupe des élèves concernés (à créer dans Participants → Groupes).
  • Fichiers : Feuilles d'exercices 2, 3 et 3¾ (et leurs corrigés, éventuellement cachés jusqu'à une date).

Pour saisir une restriction de note : Paramètres de l'activité → Restreindre l'accès → Ajouter une restriction → Note, choisir l'activité, cocher « doit être ≥ » et/ou « doit être < ». Pour « Je valide », utiliser Ajouter une restriction → Ensemble de restrictions puis « L'étudiant doit satisfaire au moins une » et trois restrictions d'achèvement. Laisser l'œil ouvert (l'élève voit l'activité grisée avec la condition) ou barré (activité invisible tant que la condition n'est pas remplie) : le barré est préférable ici, pour que chaque élève ne voie que son chemin.

Pour que les restrictions sur l'achèvement fonctionnent, activer dans les pages « Je révise / Je m'entraîne / Je vais plus loin » l'achèvement « L'élève doit afficher cette activité » (ou « marquer manuellement » si tu préfères que l'élève coche).

Section 5 – Bilan

  • Test « Bilan » : 12 questions aléatoires de la catégorie Séquence 2 – Vecteurs en cochant « inclure les sous-catégories », plus les 4 questions de Bilan – synthèse. Restriction : « Je valide (Bloc 4) » ≥ 80 %. Comportement « Feedback a posteriori » cette fois (pas d'indices) pour se rapprocher des conditions du DS.
  • URL : les deux vidéos de révision d'Yvan Monka (LE COURS et le QCM), en accès libre.
  • Badge (facultatif) : Administration → Badges → « Vecteurs », critère : test Bilan ≥ 80 %.

4. Les pages « Je révise »

Quatre fichiers Bloc N - Je révise.html. Pour chacun : ouvrir le fichier dans un éditeur de texte, copier tout le contenu entre les repères <!-- DEBUT --> et <!-- FIN -->, puis dans Éléa : ajouter une Page, dans le contenu cliquer sur l'outil « Code HTML » (</>) de l'éditeur, coller, enregistrer. Les fichiers … (aperçu).html permettent de visualiser le rendu dans un navigateur avant de coller.

Les figures sont incluses dans le code (images encodées) ; si Éléa refuse une image, elle est aussi disponible en PNG dans le dossier figures, à insérer avec le bouton image de l'éditeur. Les vidéos sont intégrées ; si l'intégration est bloquée par l'établissement, le lien texte sous chaque vidéo reste fonctionnel.

5. Ce que tu vois côté enseignante

  • Notes : le carnet de notes montre, pour chaque élève, le score d'entrée et le score de validation de chaque bloc — donc le chemin suivi.
  • Rapport d'activité → Achèvement d'activités : tableau élèves × activités, pour repérer qui est passé par « Je révise ».
  • Test → Résultats → Statistiques : le taux de réussite par question montre les points du chapitre qui posent problème à la classe.

6. Pistes d'évolution

  • Remplacer les QCM « quel point est l'image… » par des questions glisser-déposer sur image (type de question Moodle) une fois le montage rodé.
  • Ajouter des questions Calculée à valeurs aléatoires pour les coefficients k (Bloc 3).
  • Réutiliser les mêmes sous-catégories pour un test « Automatismes vecteurs » hebdomadaire de 3 questions.
